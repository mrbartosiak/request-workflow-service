# Integration execution and safety

**Scope** A-06, F-11, Q-09, R-04/05/10, DEC-08/09/10/14. **Status** Delivery invariants approved. Engines, live triggers, destinations and authority remain open. [HLD delivery](../../../Phase2-HLD/integration-delivery.md)

`DeliveryIntentFactory` builds minimal allowed obligations from approved local effects. `CommandService` commits them in the same transaction. Use an immutable effect key (destination, trusted tenant, business effect identity, connector action) with a unique constraint. Retain the exact authorized payload version or an immutable approved pointer. Use a separately scoped scheduler, pool, bounded queue and per-destination concurrency in the same service. Outbound contract `EnterpriseConnector` takes a typed plan and returns Confirmed, RetryableNoEffect, PermanentReject, AcceptedPending or Unknown plus safe evidence. It exposes optional authoritative lookup and proof capabilities expressed per connector/operation and approved tenant. Vendor calls run off the REST workflow path. [Records](records.md) · [Spring wiring](spring.md)

1. `DispatchClaimService` atomically claims a due effect and commits a numbered attempt, claimant token and bounded lease. Hold successors on an ordered stream until the predecessor is confirmed or reconciled. Bound ordered streams by tenant, target and operation family.
2. Before sending, `DispatchAuthorizationService` checks claim/generation, cancellation, payload/grants, current scope proof and confirmed publication when applicable. Commit armed attempt under the scope gate. Earlier revocation blocks send. Later revocation can leave UNKNOWN and require reconciliation. [Authority](authority-recovery.md)
3. Make the network call with its own deadline. Finish in a short transaction guarded by claimant number and generation, recording proof or safe state. Claim loss prevents stale finalization. A durable armed attempt abandoned without terminal proof is UNKNOWN, even if the transport may never have started.
4. Retry a definite no-effect transient only under current authorization, approved budget and destination limits. An accepted asynchronous job remains pending verification, with no repeat write. An ambiguous attempt follows the proof gate. Permanent rejects or unsafe ambiguity isolate only that destination/effect, surface age and evidence, and keep successors fenced when order matters.

| Ambiguity proof | Permitted recovery |
| --- | --- |
| Vendor proves at most one effect for stable key across all arrivals, with window covering old claimant sends and in-flight work | Retry under that identity within proof window, same authorized payload. |
| Prove old claimant cannot send and in-flight work cannot still apply, then perform complete current authoritative lookup | Retry only when lookup proves absence. Confirm when it proves the required effect. |
| Empty eventually consistent search, expired lease or missing evidence | UNKNOWN/quarantine. No repeat write. An audited operator can reconcile, suppress, confirm, or perform separately approved compensation. Replay uses the same proof gate. |

Statuses PENDING, CLAIMED, ARMED, ACCEPTED_PENDING, CONFIRMED, RETRYABLE, UNKNOWN, PERMANENT_FAILURE and SUPPRESSED. Audit each change and quarantine unresolved UNKNOWN. Recovery fences old claims and requires proof to reopen dispatch. Proposed budget per instance: four worker slots, one writer per destination, 2 s call deadline, up to five attempts over 15 minutes for proven no-effect transients with jitter and bounded destination wait hints. Audit exhaustion. [Recovery](recovery.md) · [Conformance](vendors.md)

**Inbound** `InboundService` verifies sender, integrity, trusted tenant/product, target mapping and allowed event shape. Unmapped or wrong-scope input cannot cause a business effect. Unique scoped receipt binds trusted event ID (or approved source/record/revision identity), semantic digest, mapping and revision. Commit receipt plus effect or processing obligation before ack. Exact repeat returns safe ack and zero additional obligations. Conflicting identity preserves first record, commits quarantine evidence and yields zero second effects. Stale events cannot supersede newer evidence. Incomplete notifications enqueue approved authoritative lookup with bounded checkpoint/overlap; restore gates dedup or reprocessing where source coverage cannot be proved. An approved lifecycle effect uses the same core authorization and mutation path. [Vendor baseline](vendors.md)

**Alternative** Broker-backed dispatch offers independent scaling and still needs an atomic local outbox or equivalent handoff. Polling reduces callback trust requirements at the cost of load and lag. REST-path vendor writes create response and partial-effect risk. Choose fake-connector conformance initially.
