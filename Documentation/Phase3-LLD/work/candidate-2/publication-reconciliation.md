# Durable publication associations

**Scope** F-05, Q-02/03/10, R-01/02/10, DEC-08/13. **Status** Proposed outside-restore proof and target fencing. [Identifiers](identifiers.md) · [Owner requirements](../../owner-identifier-requirements.md)

`PublicationJournal` is the independent publication high-water and association authority. With the local namespace lock held, `reserve(namespace, generation, ref, attemptId)` durably appends PENDING with the newly burnt ID before returning. `attemptId` is unique across writer generations and distinguishes business transaction attempts including retries. The journal rejects a fresh reservation for a ref with a PENDING or COMMITTED association, and prevents two current reservations for that ref. Repeating an authority message for the same attempt is idempotent and cannot advance the counter twice. An aborted attempt keeps its number burnt. A committed ref permanently retains its original namespace and ID. Initial enablement or migration attests a complete starting association set and preserves the authority's checkpoints. [Persistence](records.md)

The local transaction commits `publication_witness(attemptId, generation, namespace, ref, id, receiptIdentity, resultRevision)` atomically with the exact Publish effect, history, receipt and any obligation. After a known durable commit, `PublicationJournal.confirm` consumes the matching witness from the trusted committing lineage or equally authoritative commit evidence. Confirmation is idempotent. Require confirmation before releasing successful Publish or sending a Publish-dependent remote obligation. If the workflow DB committed but confirmation is unavailable, return OUTCOME_UNKNOWN on the same key and leave the obligation fenced. Replay can confirm using the same witness and returns the original ID once authorized. [Retries](retries.md) · [Dispatch](delivery.md)

| Failure window | Durable decision |
| --- | --- |
| Reserve request or reply lost | Stop that local attempt. Discard late replies. The independent journal can retain PENDING. A confirmed local rollback may close that attempt even before a delayed reserve arrives; closed attempts cannot reopen. |
| Local rollback from a known live connection or equivalent terminal proof | Mark ABORTED using proof tied to that attempt. There is no published association/effect. Never allocate the number again. |
| Local COMMIT loses acknowledgment or confirmation is unavailable | Remains PENDING until a matching trusted committed witness or affirmative rollback proof. The restored database's missing row is insufficient to abort. |
| COMMITTED association, restored target still ACCEPTED, missing, or diverged | Restore the original effects as one verified recovery action from trusted complete evidence, including receipt and obligation as applicable, or fence that target's writes and associated dispatch. No fresh Publish or synthetic reassignment. |
| Unresolved PENDING after divergent restore | Fence that ref even on a fresh key and observation. Definite abort permits a fresh publication using a higher number. If journal coverage is unproven, fence the whole affected namespace. |

While gated, readable restored data requires independent authorization proof and an owner-approved degraded-read policy. A fresh Publish with a target-specific fence returns AUTHORITY_UNAVAILABLE after submitted authorization. Ordinary scope concealment still applies. An irreversible namespace watermark is necessary even for confirmed ABORTED reservations. [Recovery](recovery.md) · [PostgreSQL evidence](postgresql-evidence.md)
