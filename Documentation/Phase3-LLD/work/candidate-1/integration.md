# Composed integration delivery

**Scope** A-06, F-11, Q-08/09, R-03–05/10, DEC-03/08/09/10/14. Atomic obligations, isolated dispatch, proof-gated repeat and inbound dedupe are approved. Common records, budgets and fixtures below are proposed. Live vendors and priorities remain deferred. [HLD](../../../Phase2-HLD/integration-delivery.md) · [Vendors](vendors.md)

**Outbound.** An approved trigger writes `OutboundObligation` in the command transaction. `Outbox` PK is `effectKey=(destination,tenant,effectId)`. Record ref/revision, operation, schema version, permitted projection reference, schedule and status. Derive `effectId` from stable operation identity and trigger slot. `Attempt` PK is `(destination,tenant,effectId,attemptNo)` with FK to the full parent key. Keep claim token, generation, lease, authorization proof, correlation, timing, safe error and confirmation reference. Changed intent needs its own effect identity. [Command append](wiring.md)

`DispatchCoordinator` takes a bounded DB claim, then checks generation, current data and cancellation, the organization policy guard and required service and actor grants. Under the guard commit the durable attempt authorization and its proof. Earlier effective revocation suppresses send. Revocation after authorization that races a potentially sent write leaves it uncertain and reconciled. I/O runs with vendor-selected credentials in `VendorConnector` outside both the workflow and claim transaction. The claim token and generation guard all local finalization. Confirm only with proof of the required remote effect. Async acceptance remains awaiting confirmation. Hold ordered successors while a predecessor is unresolved.

| Evidence or outcome | Durable state and action |
| --- | --- |
| Committed pending obligation | Start in `READY` and claim to `CLAIMED`. Recover abandoned work using its attempt evidence. |
| Proven unsent or authoritative non-application with no possible late apply | Use `RETRYABLE` for transient cases. Keep the effect ID and bound backoff. |
| Confirmed exact intended effect | Use `CONFIRMED` and store the scoped remote mapping and confirmation proof. |
| Timeout, pause after final check, revoked in transmission or evidence gap | Hold in `UNKNOWN` and reconcile. An expired lease only blocks stale local finalization. A delayed worker can still send or apply. |
| Unsafe repeat or durable contract/credential problem | Record `QUARANTINED` or `FAILED_PERMANENT` and notify the owner with a safe trace. |
| Proven unsent and denied/cancelled | `SUPPRESSED`. An uncertain attempt must be resolved before suppression can assert no remote effect. |

An ambiguous write may repeat only if vendor single-effect behavior for the stable scoped ID covers every possible old and new arrival, or an independently verified remote fence prevents old and in-flight application **and** a fresh complete authoritative lookup proves no effect. Test both orders of a delayed old worker and replacement. An empty lookup alone or a lease expiry is insufficient. An authorized operator may reconcile, confirm, suppress or pursue separately approved compensation. Manual retry uses the same safety proof.

**Inbound.** Authenticate sender, integrity, tenant, mapping and target scope. `Inbox` PK is `(sourceSystem,tenant,identityDomain,sourceIdentity)`. Trusted connector config chooses the domain from the source identity guarantee, e.g. tenant-wide event ID or approved record/revision key. Never derive it from a declared event type. Compare event type, target, version and versioned semantic digest. Commit receipt and evidence or one processing obligation before acknowledgment. Identical repeats add nothing. Conflicting reuse quarantines and preserves the first receipt. Block stale evidence overwrite and reconcile incomplete hints authoritatively. Business actions use the normal coordinator with service scope, key and observation. [Identity](access.md)

**Proposed worker settings.** Per instance, 4 worker threads, ≤2 concurrent attempts per tenant/destination (coordinate the cluster cap in shared storage), dedicated DB pool 4, claim batch 8, lease 15 s, attempt timeout 2 s, capped jittered backoff 1–60 s with at most 5 automatic attempts in 15 min and vendor-specific throttling. Quarantine unresolved uncertainty immediately. Confirmed throttling follows trusted server timing and a destination-wide limiter. Connection, queue and scheduling budgets are separate from HTTP. A broker can improve scaling and needs a durable local handoff. Synchronous remote effects add request coupling and rollback gaps. Use DB outbox initially with the fake connector.
