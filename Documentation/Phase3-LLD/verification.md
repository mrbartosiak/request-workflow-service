**Scope** F-01–11, Q-02–13, R-01–10, DEC-01/02/04/05/06/08–14. Evidence specifications for the accepted design. Phase 5 uses TDD and reports coverage. Status **planned, unrun**. [HLD evidence](../Phase2-HLD/acceptance-evidence.md)

**E1 HTTP negative cases.** Ineligible visible non-deleted state gives 409 `illegal_state` from context with no token. Concealed targets and deleted context give ordinary 404. Only separately authorized detail may show deleted metadata. Issue a valid eligible token and change facts before submit. Expect `stale_observation` or ordinary denial/concealment. Submit Reject with reasonable input and a Publish token. Expect stale observation on an authorized disclosable target. Every denial adds zero effects or history. [Context](observations.md) · [P6](postgres-evidence.md)

**E3/E4 forced release order.** Put A then B on a size-one page and deny deleted metadata. If B's Delete commits first, return only A and omit the cursor. If page handoff wins, return A and its cursor. Following it after the Delete yields no B. Restore old tuples and verify epoch +1/ordinal 1 sorts ahead. For authorized detail/context, gate before handoff. If Delete wins, return ordinary 404 with no body or token. With deleted metadata access, detail returns only allowed metadata. If release wins, detail/body or authorized context/token is handed off before Delete commits. The token later fails for a new action. For a restricted authorized payload read, force purge both ways and observe present-before, absent-after. [Access](access.md) · [Retention](retention.md)

**E6 fake fixtures.** Control the persisted remote ledger, send, lookup freshness and fence. Exercise async status, restart, throttling, permanent failure, lost response with and without remote apply, both delayed-sender orders, quarantine, safe dedupe/fencing and revocation races. Compare same `effectId` and attempt number across two destinations: distinct attempt rows and effects. For a tenant-wide event ID, change only the declared supported type: one original inbox/obligation and one quarantine discrepancy. Test exact duplicate, stale evidence and missed-notice reconciliation. An unrelated destination continues under a failing destination budget. [Delivery](integration.md)

**Evidence record.** Capture scenario, sources/fixtures, versions, actor/scopes, timing, sanitized request/result, raw durable checks and pass criterion. Attach module, API and retention compatibility deltas. PostgreSQL retry evidence has its own compact cases. Performance execution is separate and opt-in.
