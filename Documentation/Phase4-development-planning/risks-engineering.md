# Engineering and delivery risks

Use the earliest check as the owner’s trigger. The coordinator records severity, owner, affected tickets, affected exact revision, recovery action and disposition. Hold only the affected gate when other independent work is authorized. [TDD and review](execution.md) · [Choices](choices.md)

| Risk and detection point | Mitigation and contingency | Accountable role and gate |
| --- | --- | --- |
| Stale source, wrong LLD revision or confusion over ID direction at assignment intake | Verify accepted manifest and source alias in each ticket. Include override for newer identifier requirement. Reject stale context, restage exact sources and rerun impacted tests before merge. | Coordinator and reviewer · G0. Phase 6 for changed design. |
| Shared contract drift, stale branch, migration order collision, duplicate ownership at planning/merge | Assign one integrator per shared schema/API/bean surface, pin parent commit and changed contract. Run predecessor/successor CI in merged tree. Resolve schema/DTO drift first and re-review revision. Avoid merging on green isolated branches alone. | Coordinator. Ticket merge stop, Phase 6 if material change. |
| Java/PATH mismatch, Maven/Gradle or PostgreSQL unavailable at B01/B04 | Use explicitly selected session JDK, log commands and versions. Qualify approved disposable environment or remote runner. Keep missing skills/tools as readiness issue and preserve domain/validation work under its gates. | Build/fixture leads. G0/G1. |
| Driver, JSON parser, Servlet runtime, build plugin or Java 25 bytecode drift at first compile | Pin exact fixture and dependency inventory, test classfile import and required protocol behavior, record advisories. Requalify compatible candidate or keep pilot off the mandatory path and use approved existing checks. | Build/security lead. G6-P/G6-M. |
| Fault harness injects a wall-clock race or ships test controls at B32/release | Require positive blocked-party and timeout proof with negative controls, dedicated test classpath and release jar scan. Reject invalid evidence and rerun with deterministic barriers. | Verification lead. Ticket proof stop and G11. |
| API divergence, silent JSON numeric coercion or sensitive field added at B03/B45 spec example | Run seeded shape and precision regressions and projection allowlists. Stop package. Repair same unversioned contract or request design change. Pilot oasdiff is advisory until separately adopted. | API reviewer. G6-M and Phase 6 if material. |
| Submission contains fixture secrets, bundled binaries or unpublished assumptions at B48 clean clone | Scan staged files/history. Keep sensitive evidence private. Rebuild source-only snapshot with root README and clean synthetic demo. Hold downstream publication pending review and exact owner receipt. | Delivery lead. G10. |
| Environment lacks throughput fixture or teammate expects actual acceptance at B49 intake | Run readiness check, show unresolved scope and keep results pending. Keep private walkthrough conditional. Profile and execution separately authorize formal evidence. | Verification lead. G8/G9/G11. |
| Phase timing, unresolved deferral or ownership gap at milestone review | Publish ready queue and real blocker with owner/need-by, prioritize verified early slice, agree dates and explicitly close unavailable deliverables. Record missing evidence and block claims/launch that depend on it. | Coordinator and owner. G0/G10/G11. |
