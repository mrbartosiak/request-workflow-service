The route authenticates and validates the reference, query and body before opening the release transaction. Current scope proof precedes the B19 scoped row lookup. Row access requires the typed row grant, REF visibility and any applicable assignment. History additionally requires the typed history grant and, for a tombstone, deleted metadata access. An otherwise visible published row requires B17's matching committed journal entry and guarded confirmation. Only then does the history query select sequence, revision, action and both states, in ascending sequence. The application checks contiguous sequences, the Create origin, action/state continuity, edit-compatible revisions and the snapshot tail. The wire encoder writes only `ref` and `changes`, with numeric `sequence`, lower-case `action`, `from` and `to` for every change. Create carries explicit JSON null. The shared B12 handoff reprojects and checks admission under its guard. The controller receives the prepared bytes after successful transaction completion.
