## Dispatch and integration findings

| Boundary | Independent finding |
| --- | --- |
| Command and worker ownership | The synthetic composition constructs a dedicated worker transaction manager and data source and accepts a separate authority reader. The runner rejects ambient transactions. Command-only append, exclusive guard and write gates require command mode. The worker role can share-lock the organization guard through a schema-qualified function with a fixed search path and explicit execution grants. |
| Claim and arm | The claim locks a due parent and persists its token, epoch and next attempt atomically. Arm takes the organization guard, locks the current claim and checks its lease and ordered predecessors. The worker checks the independently certified writer against its workflow connection, the scope checkpoint against the guarded projection, cancellation, the configured destination, route principal, type and dispatch grant. The original committed Publish journal entry and confirmation must match the published request, revision, allocation and receipt-derived effect ID. |
| Invocation and finalization | The coordinator obtains its invocation only after the synchronous arm transaction commits. It passes only the scoped attempt, request reference and revision to the trusted local recorder. Finalization locks the current scoped attempt and requires its token, writer, generation, live lease, current writer proof and matching receipt. The parent transition and confirmation reference commit in the same transaction. The local synthetic receipt uses a unique UUID. |
| Expiry and ordering | Expired unarmed work returns to READY with an EXPIRED_UNSENT attempt. An expired armed attempt becomes UNKNOWN. The SQL checks earlier revisions at both claim and arm, using destination, tenant, request and trigger slot. A predecessor's current scoped attempt must carry confirmation evidence. The fixture models an earlier transition through a retained row because Publish is terminal in this slice. |
| Migration and compatibility | The explicit owner migration serializes with earlier schema migrations and preserves V1 and V2 envelopes. Worker grants cover mutable workflow state, scoped attempt insertion and proof reads. The worker cannot modify the obligation identity, claim token or organization guard, nor read request names or bodies. The original Publish appender retains its insert-only envelope grant. B18's guarded mapping handoff applies when a projection requires an external mapping. B24 owns remote evidence and reconciliation. |

The JDBC predicates and foreign keys retain destination, tenant, effect ID and attempt number throughout. The native fixture exercises two destinations with the same effect ID and attempt number.
