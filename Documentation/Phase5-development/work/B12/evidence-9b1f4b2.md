- Create authorizes submitted intent and verifies the signed key before receipt access. The shared organization guard covers current admission, original result permission, scope and writer recheck, trusted time and the bounded buffer offer. The accepted slot becomes drainable after the guarded transaction returns. Loss of that transaction cancels its staged slot.
- An earlier key resolves only through `OriginalReceiptProof`. The caller checks exact scoped key, generation and expiry against the returned receipt. It also checks the current result target and applicable grant. A missing, untrusted, purged or concealed outcome has one normalized fence. A trusted matching result or authorized conflict uses the existing HTTP response shapes. Earlier keys cannot claim a local receipt, reserve an ID or execute Create.
- The optional independent V005 preparation contains a private correlation, organization, result reference and revision, generations and exact result digest. Separate scoped PostgreSQL logins authorize preparation, handoff, client receipt and status reading. Append of the two later facts is idempotent for the same exact correlation. The client acknowledgment input remains independent from the HTTP response path and from the handoff source.
